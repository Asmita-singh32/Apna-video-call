# Apna Video Call – Real-Time Video Conferencing App

A real-time video conferencing application that enables users to connect through video calls, audio calls, and screen sharing.

## Features
- Real-time video and audio calling
- Screen sharing during video meetings
- Real-time communication using WebRTC
- Signaling and connection management using Socket.IO
- Peer-to-peer media communication
- Responsive user interface for video meetings

## Tech Stack
- **Frontend:** React.js, JavaScript, HTML, CSS
- **Backend:** Node.js, Express.js
- **Real-Time Communication:** WebRTC, Socket.IO
- **Version Control:** Git and GitHub

## Key Highlights
- Implemented real-time audio and video communication.
- Enabled screen sharing for collaborative meetings.
- Used WebRTC for peer-to-peer media connections and Socket.IO for signaling.

## Future Improvements

- Chat during video calls
